### Что сделано
- `index.html` — одностраничник репетитора по английскому: 10 секций (хедер, hero со фото,
  цифры, направления, обо мне, отзывы, цены, FAQ, форма записи, футер).
- Адаптив: точка перелома 900 px. Мобильная версия — одна колонка + фиксированная нижняя
  панель «WhatsApp / Записаться». Анимаций нет, только transition на ховер/фокус.
- Внешних зависимостей ноль: системные шрифты, инлайн SVG-иконки, шрифты и CSS внутри файла.
- Форма: 4 поля, HTML5-валидация + 15 строк JS-заглушки на успех (реальная отправка не подключена).

### Макеты (скриншоты)
Папка `mockups/`, снято headless-Chrome без установки чего-либо:
- `mockup-desktop.png` — 2160×9240 (1440 px, x1.5)
- `mockup-mobile.png` — 585×14955 (390 px, x1.5), полная страница
- `mockup-mobile-screen.png` — 780×1688 (390×844, x2), первый экран

### Технические решения
- Скриншоты в headless-Chrome на Windows: `--headless=new --screenshot=... --window-size=W,H`
  через `Start-Process -Wait -NoNewWindow`. `--dump-dom` на этой сборке Chrome не отдаёт вывод
  (0 байт), поэтому высоту страницы мерил иначе: снимал окно с запасом по высоте, конвертировал
  PNG в raw через ffmpeg и скриптом `scan.js` искал последнюю строку с не-белым пикселем.
- Финальный скриншот делается окном ровно по высоте страницы — тогда фиксированные элементы
  попадают в своё естественное место, и полная страница снимается одним кадром.
- `--user-data-dir` в папку Temp обязателен, иначе headless цепляется к открытому Chrome.
